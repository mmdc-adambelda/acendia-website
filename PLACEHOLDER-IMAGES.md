# Placeholder Images — Local SEO & UK SEO Cluster

All images listed below are **valid `.png` placeholder files**, generated programmatically (Node.js + the `canvas` package) with a neutral background, the exact filename displayed in the centre, the intended purpose displayed underneath, and the recommended dimensions shown at the bottom. Contrast is high enough for the label text to be clearly readable.

## How to replace a placeholder

To swap a placeholder for final photography or a designed diagram: **export the final image as a `.png` and upload it to the exact same filename and path listed below.** No HTML or code changes are required — every page already references these exact paths, so the new file takes effect immediately on next page load (allow for CDN/browser cache expiry).
